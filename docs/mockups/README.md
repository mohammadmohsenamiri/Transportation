## نکات طراحی قابل استخراج از ماک‌آپ‌ها

- پس‌زمینه تیره (dark) به‌عنوان theme پیش‌فرض بصری در ماک‌آپ‌ها دیده می‌شود؛ طبق `UX_MAP_AND_DESIGN_SYSTEM.md` theme روشن پیش‌فرض سامانه است — هر دو حالت باید با همین زبان بصری (پنل‌های لایه‌ای، border نیمه‌شفاف، رنگ‌های وضعیتی آبی/سبز/نارنجی/قرمز) پیاده شوند.
- Sidebar سمت راست با آیکن‌ها و برند «آرمان حمل» بالای آن — الگوی RTL sidebar باید از همین ساختار پیروی کند.
- کارت‌های KPI با آیکن رنگی، عدد بزرگ فارسی (`tabular-nums`) و درصد تغییر نسبت به دیروز.
- جدول مأموریت‌ها همیشه کنار نقشه (دسکتاپ) یا زیر آن در bottom sheet (موبایل) با progress bar رنگی برای هر ردیف.
- سیکر زمان به‌صورت نوار افقی زیر نقشه با دکمه «زنده» در سمت راست.
- فرم چندمرحله‌ای مأموریت با stepper افقی بالای فرم (مرسوله → مبدأ و مقصد → خودرو → زمان حرکت → مسیر → بازبینی).

این نکات باید هنگام تعریف design token در Phase 0 و اجرای هر صفحه در فازهای بعد به‌عنوان مرجع بصری استفاده شوند؛ در صورت تعارض با قواعد الزام‌آور `CLAUDE.md` (مثل RTL، بدون CDN، دسترس‌پذیری)، قواعد `CLAUDE.md` اولویت دارند.
